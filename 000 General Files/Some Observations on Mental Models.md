Conception of target system should not be confused woth the mental model the user creates of that system.

The designer's conceptualization may also differ from the image that the system itself presents to the user. Ideally, the system image will be consistent with the designer's conceptualization, and the user's mental model will thereby be consistent with both.

People's mental models can be deficient in a number of ways, it is up to designers to develop systems and instructional materials that aid users to develop more coherent, useful mental models.

##### Four things to consider in a conceptual model:
1. target system
2. conceptual model of that target system
3. the user's mental model of that system
4. the scientist's conceptualization of that mental model

Mental models naturally evolve through interaction with a target system. They need not be technically accurate, but they must be functional
