**Summary:** Task analysis is the systemic study of how users complete task to achieve their goals. This knowledge ensures products and services are designed to efficiently and appropriately support those goals.

Task analysis emerged out of industrial design (the design of training) and HFE and ergonomics. It is very important because it helps solve the **RIGHT** problem

[["Task" Definition]] Any activity that is usually observable and has a start and an end point.

Avoid confusing tasks and goals. Tasks tend to make up goals. Tasks would be what is analyzed. It is also not a job analysis (what an employee does across a period of time) or workflow analysis (how work gets done across multiple people)

In contrast, task analysis has the focus of one user, their goal, and how they carry out tasks in order to achieve it. Note that in [["Task" Definition]] it is defined as observable with a start and an end. Thus, it does not have to be limited by time.

## Task Analysis Process:
**Stage 1: Gather information on goals and tasks**
- Contextual inquiry - semiformal interview + analyst watches user in work environment.
- Interviews - asking users to recall critical incidents.
- Record Keeping - user is asked to keep records or diary
- Activity sampling - watching or recording user
- Simulation - analyst walks through steps user might take
**Stage 2: Analyze the task performed to achieve goals**
- Structure observations by order, hierarchy, frequency, or even cognitive demands
