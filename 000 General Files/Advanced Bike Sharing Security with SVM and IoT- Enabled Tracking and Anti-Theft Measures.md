### Summary
This article provides a variety of anti-theft measures that involve both active prevention and data tracking. The authors of the study propose using Support Vector Machine (SVM) algorithms and anti-theft features offered by Internet of Things (IoT) features to improve the safety of bike sharing systems. With this new method, bike theft data can be examined and utilized to find trends in security weaknesses in current bike-sharing systems. Implementing SVM and using the IoT also facilitates real-time tracking.

**SVM** is a supervised machine learning that can sort data into various groups and find patterns in large datasets. To bike sharing security, SVM examines previous data to predict possible theft occurrences depending on location, time of day, user behavior, and environmental factors.

**IoT-Enabled Tracking Devices** can be used to monitor bikes in real-time. Utilizing IoT capable devices would actualize this.
