## Introduction
Paper opens with an introduction to the tools at the disposal of a Human Factors Engineer (HFE) such as ahtropometrics, biomechanics, card sorting, task analysis, usability testing. Then task analysis is important because it is usally done before applying other HFE tools. Early forms include physical aspects of tasks, later cognitive task were included. More information can be found in [[Hierarchical Task Analysis]] by James Annett. In this paper, Intrilligator broadens the framework of Task Analysis to Multidimensional Task Analysis (MTA), which can include or subsume all other forms of task analysis. 
## Practice Innovation
It is useful to think of the MTA framework in layers of a map, where one can choose which layers to analyze and each layer can add valuable insights. When going through the layers of MTA, first one must decompose tasks such as in the traditional HTA framework. Following different layers can be observed
### Emotional Task Analysis (ETA)
- After traditional task analysis, identify emotions that might be evoked or desired during/before/after each step. These then become important contraints/oppertunities for designers.
- This framework has applications in web development, social robotics

## Other Types of Task Analysis
### Decisional Task Analysis (DTA)
- After traditional cognitive task analysis, one might identify any decision required during/before/after each step
### Information Task Analysis (ITA)
- Identify where information is created, transformed, transmitted, or used to some end. Often information is essential for making a decision, so an ITA often accompanies a DTA.
### Attentional Task Analysis (ATA)
- Identify where attention might be required to perform aspects of the task.
### Teamwork Task Analysis (TTA)
- After performing a traditional task analysis, identify where teaming is important aspect of the overall aspect
## Take Away
Traditional task analysis is great, by identifying layers of Multidimensional Task Analysis you can focus in on individual forms of task analysis to reveal new information or oppertunities.
